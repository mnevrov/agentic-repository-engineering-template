# Contributing

1. Выберите одну задачу из `docs/backlog/TODO.md` или создайте новую в `docs/tasks/`.
2. Убедитесь, что критерии приёмки измеримы.
3. Следуйте `docs/process/development-cycle.md`.
4. Не объединяйте несвязанные изменения.
5. Перед merge выполните Definition of Done.

Pull request должен отвечать на четыре вопроса:

- какую задачу решает;
- что изменилось;
- чем это проверено;
- какой остаточный риск остаётся.
