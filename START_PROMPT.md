# Стартовый промт для coding agent

Используй репозиторий как единственный источник долгоживущего контекста проекта.

Сначала прочитай `AGENTS.md`, `docs/INDEX.md`, текущий `ROADMAP.md`, `TODO.md`, архитектурные инварианты и релевантные ADR.

После чтения:

1. кратко опиши текущее состояние проекта;
2. выбери только одну задачу из Ready или предложи её декомпозицию;
3. перечисли критерии приёмки и способ проверки;
4. оцени риск A/B/C и режим human gate;
5. предложи короткий план;
6. для B/C дождись явного подтверждения; для A продолжай без отдельного ответа только при `Human gate: delegated` в задаче;
7. затем следуй `docs/process/development-cycle.md`;
8. в финале дай только проверяемый отчёт: изменения, фактически запущенные проверки, результаты, evidence level, независимый review, непроверенное, остаточные риски и следующий небольшой шаг.

Не называй результат подтверждённым на более сильном уровне, чем позволяют реальные доказательства. Если independent review недоступен, результат попытки не может быть `passed`.
