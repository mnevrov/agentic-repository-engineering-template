# CLAUDE.md

Используй `AGENTS.md` как общий контракт поведения агента.

## Начало сессии

Обязательно прочитай:

1. `docs/INDEX.md`
2. `docs/backlog/ROADMAP.md`
3. `docs/backlog/TODO.md`
4. релевантные документы из `docs/architecture/`
5. релевантные ADR

Для архитектурной итерации используй команду `/iterate`.
Для разработки одной задачи используй `/develop`.

## Ограничение размера изменения

Одна сессия разработки должна стремиться завершить одну задачу и один логически связанный набор изменений. Если задача распадается на несколько независимых частей — предложи декомпозицию до реализации.

## Подтверждение человеком

Перед кодированием явно покажи:

- выбранную задачу;
- критерии приёмки;
- затрагиваемые компоненты;
- план из нескольких коротких шагов;
- уровень риска A/B/C.

После этого не расширяй объём задачи без явной причины.
