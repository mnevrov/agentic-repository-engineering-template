# EXAMPLE-1 — Настроить реальные команды проверки проекта

**Статус:** ready  
**Риск:** A

## Зачем

Агент не должен придумывать команды сборки и тестов. Единые команды проекта должны быть доступны через стандартный интерфейс.

## Объём

### Входит

- заменить демонстрационные команды `Makefile`;
- убедиться, что `make check` и `make test` работают;
- обновить README, если нужны дополнительные зависимости.

### Не входит

- изменение бизнес-логики;
- рефакторинг приложения.

## Критерии приёмки

- [ ] `make check` запускает статические проверки проекта;
- [ ] `make test` запускает основной набор unit-тестов;
- [ ] при ошибке команды возвращают ненулевой exit code;
- [ ] команды описаны в README.
