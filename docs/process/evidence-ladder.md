# Лестница доказательств

Не все проверки одинаково сильны. Используйте точные формулировки.

| Уровень | Что было сделано | Что можно утверждать |
|---|---|---|
| E0 | код/документ создан | «реализовано», но не «проверено» |
| E1 | статическая проверка / lint / компиляция | «проходит локальную статическую проверку» |
| E2 | unit/contract tests | «проверено тестами на уровне компонента» |
| E3 | integration/e2e в контролируемой среде | «проверен сквозной сценарий» |
| E4 | реальная целевая система/данные/интеграция | «подтверждено на реальной среде» |
| E5 | повторяемый эксплуатационный сигнал | «подтверждается в эксплуатации/пилоте» |

## Главное правило

Не повышайте уровень доказательства словами.

Если тест использует mock, нельзя писать «реальная интеграция проверена».
Если live-проверка не запускалась, это должно быть видно в отчёте цикла.
