# Definition of Done

Задача считается завершённой, когда применимые пункты отмечены.

## Требования

- [ ] все критерии приёмки выполнены;
- [ ] изменение соответствует архитектурным инвариантам;
- [ ] нет скрытого расширения scope;
- [ ] нет секретов/credentials в diff;
- [ ] ошибки и граничные случаи обработаны.

## Проверки

- [ ] новые/изменённые сценарии покрыты тестами или иной воспроизводимой проверкой;
- [ ] обязательные project gates настроены и реально запускались; `NOT CONFIGURED` не считается PASS;
- [ ] интеграционные/live проверки выполнены, если требуются;
- [ ] непроведённые проверки явно перечислены и не завышают evidence level.

## Review

- [ ] self-review завершён;
- [ ] независимый clean-context review завершён и сохранён в `docs/reviews/`;
- [ ] для A нет открытых P0;
- [ ] для B/C нет открытых P0/P1;
- [ ] для C выполнен атакующий review и повторные раунды до нулевых P0/P1;
- [ ] принятые остаточные риски записаны.

## Память проекта

- [ ] задача обновлена;
- [ ] TODO/ROADMAP обновлены при необходимости;
- [ ] ADR создан/обновлён при архитектурном решении;
- [ ] документация соответствует фактической реализации.

## Трассируемость

- [ ] из коммита понятно, какую задачу он решает;
- [ ] из задачи понятно, какими доказательствами она закрыта;
- [ ] review artifact ссылается на задачу и проверенный diff/SHA;
- [ ] для существенного решения задача ссылается на requirement/ADR или явно отмечает их отсутствие как неприменимое.

## Телеметрия

- [ ] текущая попытка записана в `.ai/telemetry/cycles.jsonl`;
- [ ] запись прошла `scripts/validate-telemetry.py`;
- [ ] CI подтверждает append-only историю и наличие новой записи для содержательного изменения;
- [ ] автоматически доступные Git/duration evidence не заменены вручную выдуманными значениями;
- [ ] неизвестные метрики оставлены пустыми, а не придуманы;
- [ ] если было несколько попыток, каждая имеет отдельный `cycle_id` при общем `task_id`.
