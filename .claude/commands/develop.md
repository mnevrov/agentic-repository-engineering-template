# /develop — одна задача разработки

Цель: полностью завершить **одну** небольшую задачу с доказательствами и измеримой телеметрией.

## 1. Контекст

Прочитай `AGENTS.md`, `docs/INDEX.md`, ROADMAP/TODO, архитектуру, ADR, `docs/process/traceability.md`, `docs/process/telemetry.md` и файл выбранной задачи.

Зафиксируй время начала цикла.

## 2. До кода

Покажи человеку:

- ID и название задачи;
- критерии приёмки;
- затрагиваемые файлы/компоненты;
- уровень риска A/B/C;
- режим human gate;
- короткий план;
- способ проверки результата.

Для B/C дождись явного подтверждения. Для A без отдельного подтверждения можно продолжить только при явном `Human gate: delegated` в задаче. Опасные/необратимые действия всегда требуют подтверждения.

## 3. Реализация

1. Добавь тест или иной воспроизводимый проверочный сценарий.
2. Получи ожидаемое падение, если применяется TDD.
3. Внеси минимальную реализацию.
4. Запусти локальные проверки.
5. `NOT CONFIGURED` не считать успешной проверкой.
6. Не исправляй несвязанные проблемы в том же цикле.

## 4. Проверка

- самопроверка diff;
- обязательная независимая проверка с чистым контекстом;
- сохранить её результат в `docs/reviews/<TASK-ID>-review.md`;
- для B/C — усиленная проверка по `code-review.md`;
- для C — повторять атакующий review до отсутствия нерешённых P0/P1.

Если независимый review невозможно выполнить, завершить попытку как `partial`/`failed`, а не `passed`.

## 5. Завершение

Проверь `definition-of-done.md` и сформируй evidence summary:

- команды;
- результаты;
- ссылки/файлы доказательств;
- evidence level E0–E5;
- непроверенное;
- остаточные риски.

Обнови задачу, ROADMAP/TODO, traceability и документацию.

## 6. Телеметрия

До финального коммита запиши текущую попытку через `scripts/record-cycle.py`.

Обязательно передай:

- `--task`;
- `--started`;
- `--ended`;
- `--result`.

`record-cycle.py` сам фиксирует доступные Git/duration evidence. По возможности добавь только реально доступные значения: модель/провайдер, input/output tokens, время инструментов/тестов/CI, review rounds, P0/P1, участие человека, примерную стоимость, live-validation, дефекты и evidence.

Не выдумывай отсутствующие числа.

Если попытка завершилась `failed`, `partial` или `aborted`, она всё равно должна попасть в журнал. Следующая попытка использует новый `cycle_id` и тот же `task_id`.

После записи выполни:

```bash
python scripts/validate-telemetry.py
python scripts/telemetry-summary.py
```

Один завершённый цикл — один осмысленный коммит.
